# Glosarium pstack

| Istilah sumber | Padanan Indonesia | Catatan |
| --- | --- | --- |
| skill | skill | Unit instruksi yang dapat dipanggil. Pertahankan nama teknisnya. |
| playbook | playbook | Alur kerja terarah; jangan samakan dengan skill. |
| blast radius | - | Dipertahankan dalam bahasa Inggris seperti nama skill/playbook. Artinya dampak perubahan: cakupan bagian yang mungkin terdampak perubahan; sebagai penjelasan, bukan pengganti di prosa. |
| review | tinjauan | Pemeriksaan perubahan atau hasil kerja. Gunakan `code review` bila nama proses spesifik. |
| automations | automasi | Fitur/alur otomatis pstack. |
| agent | agent | Pertahankan pada nama dan konteks teknis pstack. |
| prompt | prompt | Instruksi yang diberikan kepada model atau agent. |
| context | konteks | Informasi yang tersedia bagi model saat bekerja. |
| workflow | alur kerja | Urutan langkah untuk menyelesaikan tugas. |
| verification | verifikasi | Pemeriksaan bahwa hasil memenuhi kriteria. |
| pull request (PR) | pull request (PR) | Pertahankan nama fitur GitHub; setelah pengenalan boleh gunakan PR. |
| diff | diff | Perubahan baris kode yang ditampilkan alat version control. |
| source of truth | sumber acuan | Sumber yang dinyatakan paling otoritatif untuk suatu fakta. |

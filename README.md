# pstack-indo

Panduan **pstack** (plugin Cursor karya Lauren Tan) dalam bahasa Indonesia, diterbitkan sebagai EPUB dan PDF.

Terjemahan tidak resmi. Rangka repo (tooling build, pedoman gaya, glosarium, kerangka bab) sedang disiapkan; naskah terjemahan menyusul.
